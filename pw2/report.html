1. Мета роботи

Навчитися аналізувати макет Figma у Design Mode, отримувати графічні ресурси та відтворювати секцію Hero засобами HTML і CSS.

2. Короткі теоретичні відомості

HTML задає семантичну структуру сторінки. CSS описує оформлення, розміри, відступи й адаптивність. Flexbox розміщує елементи вздовж головної та поперечної осей. У Figma параметри тексту, кольорів і геометрії слугують основою для відповідних CSS-властивостей.

3. Завдання

Проаналізувати Landing Page UI Kit, створити сторінку з навігацією та Hero, підключити зовнішні стилі, додати графіку, забезпечити адаптивність і розмістити результат на GitHub Pages.

4. Хід роботи

  1. Файл Landing Page UI Kit.fig імпортовано до Figma Drafts. Макет переглянуто через прототип.
  2. Визначено структуру Home: Top Bar, Header, Video, Logos, Features, User Feedback, CTA, Footer. Для основної частини роботи обрано Header з назвою Pet Store & Beyond.
  3. Зафіксовано розміри Hero 1280 × 600 px, фон #F7F5FD, заголовок 80/90 px і основний текст 18/32 px.
  4. Оригінальне фото двох собак отримано з ресурсів локального .fig-файлу та збережено в assets/hero.jpg.
  5. Створено pw2/index.html та pw2/css/style.css. Основна структура: header, nav, main, section, footer. Застосовано Flexbox, загальне скидання відступів, медіазапити й альтернативний текст зображення.
  6. Нижні допоміжні секції оформлено самостійно; вони не є точною копією всього макета. Знак логотипа відтворено засобами CSS. Основний об’єкт відтворення — Hero.

Макет: Landing Page UI Kit.

5. Відповіді на контрольні питання

  1. Для вимірювання відстані виділяють елемент, утримують Alt і наводять курсор на інший елемент.
  2. SVG зберігає чіткість при масштабуванні та зазвичай підходить для іконок і логотипів краще за растрові формати.
  3. Ctrl + клік дозволяє глибоко виділити вкладений елемент; на macOS використовується Command.
  4. Розмір шрифту та міжрядковий інтервал містяться у блоці Typography правої панелі Design.
  5. Параметру Gap відповідає CSS-властивість gap, а також row-gap і column-gap.
  6. HEX-код кольору міститься у Fill, параметри тіні — у Effects.
  7. Експорт 2x забезпечує вищу чіткість растрової графіки на екранах із підвищеною щільністю пікселів.
  8. Padding задає простір усередині меж блоку, margin — відстань між блоком і сусідніми елементами.

6. Висновок

Створено адаптивну HTML/CSS-сторінку на основі Hero макета Figma. Використано семантичні елементи, Flexbox і оригінальну графіку. Отримано практичні навички перенесення властивостей дизайну у CSS.
